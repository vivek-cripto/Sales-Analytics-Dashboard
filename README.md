# AdventureWorks Sales Analytics Dashboard

## 📌 Project Overview

An interactive **Sales Analytics Dashboard** built using **Power BI, DAX, and Excel** to analyze business performance across revenue, profit, orders, products, customers, and returns.

## 📌 Problem Statement

The objective of this project is to transform sales data into an interactive dashboard that helps users:

- Monitor overall sales performance
- Analyze revenue and profit trends
- Identify top-performing products and customers
- Compare sales across regions
- Track orders and return rates

## 📊 Key Metrics

- **$25M** Revenue
- **$10M** Profit
- **25K** Orders
- **2.17%** Return Rate
- **17K** Unique Customers

## 🛠️ Tools Used

- **Excel** – Data preparation and analysis
- **Power BI** – Dashboard development and visualization
- **DAX** – Measures, KPIs, and calculations

## 📈 Dashboard Pages

### 🔹 Sales Overview
- Revenue and profit KPIs
- Revenue trends
- Orders by category
- Top 10 products
- Monthly revenue, orders, and returns

### 🔹 Regional Analysis
- Geographic sales visualization
- Continent-level filtering
- Regional performance analysis

### 🔹 Product Analysis
- Orders vs Target
- Revenue vs Target
- Profit vs Target
- Profit trends
- Return rate analysis
- Product-level performance

### 🔹 Customer Analysis
- Unique customers
- Average revenue per customer
- Orders by income and occupation
- Top customers by revenue
- Customer-level sales analysis

## 🚀 Features

- Interactive KPI tracking
- Dynamic filters and slicers
- Product and customer analysis
- Regional sales visualization
- Target vs actual analysis
- Return rate tracking
- Interactive Power BI dashboard
